# E84 — structured surface rules on the contradiction holdout

> Follows `E83_CONTRADICTION_RULES.md`, which measured the WordNet
> antonym + negation rule at precision 1.000, recall 0.143 on pairs not built
> from a dictionary, and named the five classes it missed: number, comparison,
> modality, quantifier scope and argument order. E83's conclusion was "this is
> where a parser earns its cost". Before paying for one, E84 asks how far
> targeted surface rules get — still no model, still no tagger.

**Run:** `python3 benchmarks/conatus/e84_structured_rules.py` over
`fixtures/contradiction-holdout.json` — 36 hand-written pairs, seven
contradiction classes (25 pairs) plus 11 paraphrases that must not fire. No
pair is generated by inserting a dictionary antonym, so no rule grades its own
generator (the E83 lesson).

## Result

**Precision 1.000, recall 0.840 on the holdout.** Same fixture discipline as
E83, seven rules instead of two, zero inference.

| class | fired | total |
|---|---|---|
| numeric | 5 | 5 |
| comparative | 3 | 3 |
| modal | 4 | 4 |
| quantifier | 3 | 3 |
| roles | 3 | 3 |
| implication | 0 | 3 |
| antonym | 3 | 4 |
| **total** | **21 / 25** | |

None of the 11 paraphrases fired. Rule firings across the fixture: numeric 5,
comparative 3, modal 5, quantifier 3, roles 3, antonym 2, negation 1, domain 2.

## What this changes

* **E83's ceiling was the rule set, not the approach.** The offline,
  zero-inference arm moves from recall 0.143 to 0.840 by adding five targeted
  rules, each aimed at one class and each able to fire wrongly — and none did.
  The parser's cost is no longer justified by the gap E83 measured; the gap
  E84 measures is 4 pairs in 25.
* **The remainder is one class, not five.** `implication` (0/3) is missed
  outright — "supply is sufficient" against "supply will run out" shares no
  lexical, numeric, modal or order cue the rules can see. The last antonym
  miss is a dictionary gap, not a rule gap. If a model earns its way in, it
  earns it on implication pairs specifically.
* **Precision 1.000 is a small-denominator statement.** Eleven paraphrase
  guards, no adversarial near-contradictions. The E83 limit applies with more
  force here: the fixture is hand-written by the same person running the
  experiment, on the repository's own subject matter.

## What would have to come next

1. **Adversarial fixtures.** Pairs *designed* to fire each rule wrongly (same
   frame, different quantity, but not contradictory; opposed modals that are
   consistent, e.g. permission vs prohibition). Precision 1.000 without these
   is untested confidence.
2. **Implication pairs** are the single named target for an NLI arm — the
   comparison E83 left unrun (NLI beats cosine at 120B, collapses at 7B)
   becomes decidable on a fixture where the rules measurably fail.
3. **Second rater** on the fixture labels before any recall number travels
   outside this repository.

Relation to the literature sweep (PLAN.md E4, R3): the three-way relation
discriminator (synonym/antonym/co-hyponym) addresses the antonym dictionary
gap; nothing in it addresses implication, which keeps the model arm scoped to
one class rather than a replacement of the rule set.
