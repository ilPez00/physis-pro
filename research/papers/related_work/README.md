# Related-work audits

One file per live paper. Path note: the mission asked for
`research/papers/<paper>/RELATED_WORK_AUDIT.md`; the papers here are flat
`.tex` files, so creating `paper1_failure_priors/` next to
`paper1_failure_priors.tex` would invite confusion with a build directory.
Audits live in this one directory instead, named `<paper>_RELATED_WORK_AUDIT.md`.

Searches ran 2026-09-25. Where a search returned nothing usable it is recorded
as such rather than padded.
