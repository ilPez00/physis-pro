Notebook

A notebook is your dashboard: pick the panels that matter to your job, order them, size them. Every other page in this product is a composition we chose; this one is yours.
Pinned searches are the point. Add a Pinned search cell with a query you keep asking — "no fault found" in line-2 — and it is answered live every time you open the page.
Notebooks are stored per user on the server, so yours follows you to the machine wired to the projector. Export hands a colleague the layout as JSON — it carries panel names and settings, never code.
