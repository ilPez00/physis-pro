Physis · About

the engine, not the marketing

A Rust runtime for ontological classification, coherence tracking, and dream planning.

What it is

Physis reduces any input — text, image, video, audio, a machine reading, a code log, a human action — to one shared vector space, classifies it against a 70-cell semiotic grid (5 domains × 14 modes, ~630 authored entries), and tracks each thing's coherence: did it work? +1 / 0 / −1. A background "dream" loop replays the failures to propose corrective actions.

What sits on top

  • Industrial — OEE (A×P×Q + six-big-losses Pareto), predictive maintenance (σ-distance anomalies, RUL), SMA-30 inventory forecast.
  • Datawork — space·time·cause addresses on every file, an append-only causal ledger queryable in plain facets.
  • Ingest — documents, mailboxes, Obsidian vaults, browser history, OPML feeds, chat logs, Praxis life-logs → labeled core nodes.
  • Quality loop — reported failures persist, penalize their cell, and keep proposing countermeasures.
  • Semiotic editing — exchange a node's content while its structure (id, verdict, edges) survives.

How it runs

CLI (physis-pro), HTTP server (physis-pro-web), an MCP server for agent tool-use, a TUI, and a voice binary. Multi-tenant by X-Physis-User header. License-gated by an offline Ed25519 key.
