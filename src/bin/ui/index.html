Physis · industrial intelligence

offline-first · ontology-driven · Rust

One engine that classifies your shop-floor text, telemetry and documents into a live ontology, predicts failures, and proposes the next action — air-gapped, no cloud required.

Physis reduces any input — a CSV export, a machine reading, a shift note, a mailbox — to one shared vector space, judges whether each thing worked, and replays what didn't to propose the fix. It produces an Italian shift report your production lead can actually read, not another dashboard.

Classify on a 70-cell grid

Every input lands on a FABRICATE·WORK cell — a domain × mode meaning grid with 630+ authored entries, not a black-box model.

OEE & predictive maintenance

Availability × performance × quality with six-big-losses Pareto, σ-distance anomaly scoring and remaining-useful-life projection from your own baseline.

Quality feedback loop

Report a failure once and the engine remembers it, penalizes the cell, and keeps proposing countermeasures — persistence that changes behavior.

Space · time · cause

Every file carries where it lives, when it matters and why it exists, in an append-only causal ledger you query in plain facets.

Air-gapped by design

Deterministic classification and an offline license key. No network, no external fonts or CDNs — the install runs where your data cannot leave.

Speaks to agents (MCP)

An MCP server and a plain HTTP API any agent framework can call. Give your agent a semiotic memory.
