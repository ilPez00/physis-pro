Physis Pro — Retired

`physis-pro` is no longer a development target. `physis-next` is the only Physis.
Retired 2026-10-04 (operator directive). The `physis-pro` industrial backoffice engine is retired. The only active Physis project is physis-next (`~/dev/physis-next`) — the CLI physis, the physis-* crates, the MCP server physis serve, and the commercial physis-context-mcp product. See physis-computer for the public engine and /home/gio/dev/physis-next/README.md for the product readme.

What still runs today

praxisweb.xyz still proxies its Physis surface to a running physis-pro-web process on 0.0.0.0:19876 (PHYSIS_API_URL). The 8 machines the praxis demo exposes — chronos, topos, harmony, polis, soma, elenchus, lex, empedocles — exist only in that retired engine; physis-next has no machines. Migration off that process is not done and is the open work the retirement created.

Licence

`physis-pro` was never Apache-2.0: its LICENSE.txt is a proprietary EULA ("licensed, not sold"). `physis-core` is Apache-2.0 per its manifest and is a separate crate.
