# MS-002 — Delta-engine determinism and replay contract

> **REPORT-ONLY packet.** No production source was edited. This report records
> evidence gathered against `physis-core/src/delta_engine.rs` to define the
> correctness contract a replay harness in `research/multiscale/MS-002/` must
> honor. Verified against checkout on `2026-09-20` (main branch).

---

## Amendment A1 — MANDATORY for all successors

`EvaluationContext::find_neighbors` (`delta_engine.rs:252-298`) returns
`HashSet` iteration order with **no sort**. This is the single most important
fact in this report:

- `OntologyDeltaReport.affected_nodes` (`node_deltas`) is built in
  `dfs_collect` visitation order (line 602, driven by the adjacency map that
  `find_neighbors` populates at line 297). Its element order is **UNSPECIFIED**.
- `net_coherence_delta` (`net_delta`, line 760/958) is an f32 running sum in
  that same unspecified order. It is reproducible to **epsilon 1e-6**
  (`classify_delta` epsilon at line 586), **never bit-identical**.
- Compare `node_deltas` **as a set sorted by `node_id`** — never as a positional
  vector.
- `net_coherence_delta` compares **to epsilon 1e-6**, not bit-exact.
- Sorting the wave itself is a **core source change** that belongs in its own
  packet, not in MS-002. MS-002 honors A1 rather than fixing its root cause.

## Evidence

Inspected: `physis-core/src/delta_engine.rs` (1065 lines), plus the test
artifacts `physis-core/tests/test_delta_engine.rs` (495 lines) and
`physis-core/tests/epistemic_p1.rs` (359 lines).

### `evaluate_mutation` — lines 689-962

```
pub fn evaluate_mutation(
    ctx: &mut EvaluationContext,
    mutation: OntologyMutation,
) -> OntologyDeltaReport
```

- **Inputs:** `ctx: &mut EvaluationContext` (mutable shadow frame), `mutation:
  OntologyMutation` (target node id + `MutationOp`).
- **Output:** `OntologyDeltaReport` (lines 390-404).
- **Algorithm (6 phases):**
  1. Pushes `mutation` into `ctx.mutation_log` (line 693).
  2. **A7 no-perturbation invariant** (lines 695-713): a zero-shift
     `EmbeddingShift` (old == new) returns an empty report immediately — no
     shadow writes, zero transitions.
  3. **Isolation** (lines 717-742): clones the target node into
     `ctx.shadow_nodes`; computes `source_sim` = `cosine_sim(old, new)` for
     shifts, `1.0` for property/relation ops.
  4. **Topological wave** (lines 745-756): builds adjacency via
     `build_adjacency()`, then `dfs_collect` (line 602) walks DFS with
     `GAMMA.powi(depth)` decay (line 615) and `MIN_IMPACT` cutoff (line 616).
  5. **Local recalculation** (lines 758-786): per affected node, captures
     `prev_coherence` from the effective node, recomputes `new_coherence` via
     `compute_coherence` (line 219), persists into shadow, accumulates
     `net_delta` (line 778), and pushes an unsorted `NodeDelta` into
     `node_deltas` (line 780).
  6. **Hypothesis evaluation** (lines 788-952): selects revisions via
     `depends_on_walk` (line 803); computes `coherence_delta`; for shifts
     beyond `DEGRADATION_THRESHOLD` (0.25, line 46) routes through
     `route_transition` (line 479) → `AutoApply` / `StrategicReview` /
     `CoreProtected`.

### Shadow frame mechanism (lines 110-213)

- `EvaluationContext` holds `base_nodes` (read-only `&'a [CoherenceNode]`,
  line 119), `base_hypotheses` (line 121), `edges` (line 123), `shadow_nodes`
  (owned `HashMap`, line 125), `shadow_hypotheses` (line 127), `mutation_log`
  (line 129). Base refs are never mutated.
- `effective_node` (line 153): shadow copy if present, else base lookup.
- `ensure_shadowed` (line 193): clones from base into the shadow map on first
  touch, returns `&mut CoherenceNode`.
- `effective_nodes_all` (line 161): shadow-first, then base-unshadowed.

### `find_neighbors` — lines 252-298

```rust
pub fn find_neighbors(&self, node_id: &str) -> Vec<String> { ... }
```

Three link classes, merged into a `HashSet<String>`:
1. Typed edges, both directions (lines 256-262).
2. Shared `cell_pin` (domain, mode) across base + shadow nodes (lines 264-278).
3. Label-prefix links — `nlabel.starts_with("parent → ")` (lines 280-295).

Terminator — **line 297, no sort:**
```rust
neighbors.into_iter().collect()
```
`HashSet` iteration order is non-deterministic across runs (hasher-seeded).
This is the root of Amendment A1.

### `build_adjacency` — line 301

Eagerly calls `find_neighbors` for every effective node (line 304); inherits
the non-determinism. Used by `dfs_collect` via the adjacency map (line 745).

### `depends_on_walk` — line 312 (IS sorted)

BFS over **declared `DependsOn` edges only** (line 317). DependsOn dependents
are reverse-indexed into `dependents_of` (line 315); each list is sorted +
deduped at **lines 324-325**:
```rust
list.sort_unstable();
list.dedup();
```
Bounded by `MAX_REVISION_WALK_NODES = 5000` (line 57); truncation is recorded
(line 337). Cycle-closing edges are captured, never re-enqueued (line 357).
`RevisionWalk.steps` / `dependents` are BFS-ordered and deterministic **given
the edge input**; unlike `find_neighbors`, this path is explicitly sorted.

### `dfs_collect` — line 602 (NOT sorted in output)

```rust
fn dfs_collect(current_id, adjacency, depth, visited, affected, source_sim)
```
Depth-first; impact = `source_sim × GAMMA^depth` (line 615). Stops on
`depth > MAX_PROPAGATION_DEPTH` (5, line 49) or `impact < MIN_IMPACT` (0.01,
line 52) or `visited` hit (line 610). `affected` is a `Vec<(String, f32)>`
pushed in visitation order — and visitation order inherits
`find_neighbors`'s unsorted adjacency. **Output order is unspecified.**

### `compute_coherence` — line 219 (scans entire graph per call)

```rust
pub fn compute_coherence(&self, node_id: &str) -> Score
```
Collects **all** effective nodes via `effective_nodes_all()` (line 220), maps
cosine similarity to the query node over every other node, sorts descending,
truncates to `k = 5.min(all.len() - 1)` (line 230), and averages. Every call
is therefore an **O(n) full-graph scan** with a hidden sort. Called once per
affected node inside `evaluate_mutation` (line 770), so the wave's local
recalculation phase is O(affected × n). No counter or persistence instruments
this cost.

### `revised_hypotheses` — line 816 (IS sorted)

Inside `evaluate_mutation`, the hypothesis id list is built by walking
`walk.steps` (BFS order); within each step the matching ids are collected and
**sorted at line 816** (`matching.sort()`), then deduped across steps (line
818). This is deterministic per-step.

### `node_deltas` — line 780 (NOT sorted)

Built by iterating `affected` (the `dfs_collect` output) in visitation order
and pushing `NodeDelta` with no subsequent sort. Order is unspecified per A1.

### Production callers

- `evaluate_mutation` is re-exported from `physis-core/src/lib.rs:246` but has
  **zero production call sites** — the only call paths are inside
  `#[test]` bodies in `test_delta_engine.rs` and `epistemic_p1.rs`.
- `propagate_delta` (defined `src/dependency/mod.rs:49`) has **zero production

- The duration seam is **not instrumented**: `grep -n "duration\|Duration\|

  no persistence.

### Comparison contract (derived from source)

| Field | Ordering rule | Rationale |
|-------|--------------|-----------|
| `node_deltas` (`affected_nodes`) | Set **sorted by `node_id`** | `find_neighbors` (line 297) and `dfs_collect` (line 602) are unsorted |
| `net_coherence_delta` | Epsilon **1e-6** (`classify_delta`, line 586) | f32 running sum (line 778/958) in unspecified order |
| `revision_walk.steps` | Positional (BFS) | `depends_on_walk`, sorted (line 324), deterministic given edges |
| `revised_hypotheses` | Positional (per-step sorted) | line 816 `matching.sort()` |

| `adjudications` | Positional | same loop as shifts |

## Limitations

- **`rg` not available in this shell.** All searches used the Grep tool or
  `grep -n` via bash; no `ripgrep` invocations were emitted.
- **`compute_coherence` hidden cost (line 219).** Each call is an O(n)
  full-graph scan (`effective_nodes_all()` + sort + truncate to k=5). Across
  the wave it is O(affected × n), but this cost is **not instrumented** — no
  counter, no timing field in `OntologyDeltaReport`. The report surfaces
  `net_coherence_delta` but not how long coherence recomputation took.
- **No production callers.** `evaluate_mutation` (re-exported `lib.rs:246`) and
  `propagate_delta` (`dependency/mod.rs:49`) are both exercised only by tests.
  A replay harness therefore has **no production baseline** to compare against
  — only the test fixtures in `test_delta_engine.rs` (7 tests) and
  `epistemic_p1.rs` (7 tests).
- **Duration seam not instrumented.** `grep -n "duration\|Duration\|elapsed\|
  start_time\|Instant"` over `delta_engine.rs` returns zero hits. No wall-time
  or CPU counter exists in the report path.
- **`node_deltas` order is unspecified (A1).** Repeated identical runs over a
  graph with ≥2 neighbor-linked nodes may yield different `node_deltas`
  orderings and minute `net_coherence_delta` differences (float summation order).
  This is a property of `find_neighbors`, not a harness defect.
- **No frozen-manifest artifact checked in.** The packet spec (step 42) calls
  for frozen data manifests/revisions/seeds/splits; none exist in the repo yet.
  This report records the *code* contract only — the harness in
  `research/multiscale/MS-002/` is a design stub, not an executable.
- **Report-only.** Acceptance criterion #2 of the packet ("one runnable check
  with no-op, local, fanout, cycle and disconnected mutations") requires a
  companion test binary in `physis-core/tests/`. That binary is **not** part of
  this report-only packet and is deferred (see Decision).
