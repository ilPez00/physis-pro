## What would unblock

1. Pull `cross-encoder/nli-deberta-v3-xsmall` weights into this environment and test against the 86-pair gate set

## Limitations

- NLI precision is a LOWER BOUND: corpus has only 2 gold contradiction pairs. Any real contradiction NLI finds that isn't in the gold set counts as a false positive.
- The gate requires an OpenAI-compatible chat completions endpoint, not a raw ONNX model. A server wrapper is needed for local cross-encoders.
- 5/86 pairs returned HTTP 503 from NVIDIA endpoint (retried successfully).
