## 2. Shared `EmbedderHealth` struct

One struct now owns the embedder health state, guaranteeing a single source of
truth across every surface:

```rust
pub struct EmbedderHealth {
    pub degraded: bool,
    pub semantic: bool,
    pub self_test: bool,
}
```

- `degraded` — true when a trained model failed self-test and fell back to
  random-projection (or a non-RP embedder failed self-test)
- `semantic` — true when the embedder is a genuine semantic model (passed
  self-test and is not deterministic RP)
- `self_test` — whether the embedder passed the semantic self-test at startup

Constructed from `SharedCtx` via `EmbedderHealth::from_shared_ctx(&shared)` or
directly from the three boolean fields. Unit tests in
`embedder_health_tests` verify construction from each real embedder kind
bge-base, MiniLM fallback, random projection) and warning field presence logic.

## 3. Behavioural changes

- **Degraded embedder + query** → response carries a visible `degraded` field;
  CLI prints to stderr; MCP tool result includes it. HTTP 200 with warning, not
  silent success.
- **Health endpoint** (`/health`) now returns `embedder_health` with full
  degraded/semantic/self_test state, so clients can detect degraded mode
  uniformly.
- All surfaces previously reading `state.shared.degraded`/`state.shared.semantic`/
  `state.shared.self_test` now read from the shared struct, ensuring consistent
  behaviour.
