# PH-003 — Licence claims must agree everywhere

Decision (RUNG 5, by Gio, 2026-09-12): "physis-core is Apache-2.0;
physis_pro is proprietary (EULA in LICENSE.txt)". No relicensing — the pages
were wrong, the metadata was right. Canonical string stored verbatim in
`scripts/licence-claim.txt`.

## Options drafted (agent) and the choice (human)

| option | statement | consequence |
|---|---|---|
| **A (chosen)** | physis-core Apache-2.0; physis_pro proprietary (EULA) | zero legal risk — matches `physis-core/Cargo.toml` (`license = "Apache-2.0"`), root `Cargo.toml` (`license-file = "LICENSE.txt"`, comment forbidding MIT), and both `LICENSE.txt`/`LICENSE-APACHE`; pages needed correction only |
| B | physis-core MIT; physis_pro dual-licensed (MIT API + commercial EULA production) | matched the old pages but required relicensing physis-core to MIT + metadata edits — rejected as higher risk and inconsistent with root comment |
| C | physis-core MIT; physis_pro proprietary | core relicensing required, dual claim dropped — rejected (same core cost as B, no page alignment gain) |

## What was changed (after the decision existed)

1. **Four customer pages** carry the canonical claim verbatim (body + footer):
   `index.html`, `src/bin/ui/about.html`, `src/bin/ui/pricing.html`,
   `src/bin/ui/customer_dashboard.html`. The old MIT/dual claims are gone.
2. **`scripts/licence-claim.txt`** — the canonical string, single source of truth.
3. **`scripts/tests/licence-consistency.sh`** — the gate test: every page must
   contain the claim byte-identically; `physis-core/Cargo.toml` must declare
   `Apache-2.0`; root `Cargo.toml` must not declare a real `MIT` licence line.
4. No legal text invented; `LICENSE.txt` untouched (per Never).

## Gate

```
bash scripts/tests/licence-consistency.sh          PASS (exit 0)
corrupt one page (is Apache-2.0 → is MIT)          FAIL exit 1, as required
revert + rerun                                     PASS
```
