## 2. What was missing, and is now added

1. **The packet's unit gate had no test carrying `semantic_self_test` in its
   name.** `cargo test semantic_self_test` matched **zero** tests and exited 0 —
   a silent gate. The existing probe test is `random_projection_fails_the_
   semantic_probe`, which the design mistakenly counted as matching.
   Added `embed::tests::semantic_self_test_rejects_lexical_and_gates_real_weights`
   (arm a: random projection must fail — always checkable; arm b: the flat
   MiniLM export must pass when present).
2. **The "skipped if weights absent" arm was silent.** The skip now prints
   `SKIP semantic_self_test[real weights]: models/model.onnx is absent …` *and*
   asserts the absence, so the skip cannot be a quiet green: dropping the export
   at `models/model.onnx` converts the test into the real-weights arm instead of
   leaving it green forever.
3. **No test exercised the CLI contract.** Added
   `semantic_self_test_cli_exits_nonzero_for_the_offline_embedder`
   (`tests/system_interface.rs`): runs the real binary as `selftest` with
   `PHYSIS_EMBEDDER=random-projection` and no licence file, and requires exit
   **1** with a named embedder and a `FAIL` verdict — the instrument working,
   not a warning printed beside exit 0.

## 4. Surprises

- **`models/model.onnx` does not exist.** Design §3 hole 3 asserted the flat
  MiniLM export lived there; it does not (the models dir holds
  `bge-base-en-v1.5`, `bge-small-en-v1.5`, `nli-deberta-v3-xsmall`). A caveat in
  a design doc is a fact with a date on it, same as in a report. The conditional
  arm is therefore the live one, and it now says so out loud.
- **An abandoned, non-compiling WIP sat in `src/web/mod.rs`** (mtime 16:30,
  never committed on any branch — `git show <c>:` differs from the worktree for
  every candidate commit). It duplicated the `semantic` computation and added
  `&& embedder_kind != "random-projection"`, which is already implied by
  `self_test_ok == false` for the offline embedder. It broke the file's braces
  and the whole crate did not compile on arrival. Preserved as a patch at
  `/tmp/opencode/physis-wip-web-mod.patch`, then `git checkout --` restored
  HEAD. No behaviour was lost: §1's `/health` pins already hold at HEAD.
- **`select_embedder` picks ollama before the ONNX legs** when a local ollama
  serves an embedding model, so the CLI selftest measured `ollama-embed` on
  pansa, not `bge-base`. That is the documented cascade order, not a defect —
  recorded so the next reader does not mistake the label for a hardcoded choice.

## 5. Unknowns → new packets

1. **The probe has no lower bound on the distractor arm.** A degenerate
   embedder emitting near-identical vectors for everything passes if the related
   pair happens to score `+0.05` higher. A four-point probe (related high,
   distractor low, absolute floor) would close it; not required by this packet.
2. **`semantic_self_test` runs the full probe on every server boot** for the
   selected candidate (plus the cached model verdicts). Measure whether the
   ~50 s `selftest` first-run cost is model load or probe; if probe, memoize.
3. **The heavy candidates are cached, the cheap ones are not.**
   `select_embedder` routes bge-base/bge-m3 through `SelfTestCache`, whose key
   is version-prefixed (`{SEMANTIC_PROBE_VERSION}:{label}:{path}:{mtime}`), so a
   verdict recorded under `v1` cannot be reused — checked, no gap. But the
   pre-cache legs (`try_primary`, bge-small, ollama) re-probe every run. Fine at
   current sizes; worth a packet if a future candidate is slow to load.
