## Harness

`scripts/bench-pack.sh` (new, committed — the script did not exist):
- Builds a synthetic store (N docs, default 1000, configurable via
  `--nodes`), measures cold pack (fresh process + fresh embed cache) and
  warm pack (same store + cache reuse) with `date +%s.%N` wall deltas.
- Integrity: two consecutive runs must produce an identical sorted chunk list
  (greps `score  path:line-range  (N tokens)` lines, sorts, diffs); exits 5
  on drift. Node count reported from the list.
- Emits `PACK_BENCH cold=Ws warm=Ws nodes=N` to `bench/bench-pack.results`
  (gitignored via `bench/*.results` in `.gitignore`) + human table.
- `--assert-warm-under` / `--assert-cold-under` exit 1 with expected-vs-actual
  on breach. `bash -n` clean.

## Fixes found during implementation

1. Licence isolation: `enforce()` calls `load()` even in dev mode, so a fresh
   `PHYSIS_DATA_DIR` temp dir exits 2 ("no licence found"). Fix: export
   `PHYSIS_LICENSE_FILE=$HOME/.physis/license.key` alongside
   `PHYSIS_ALLOW_DEV_LICENCE=1` — cache isolation kept, licence still loads.
2. Chunk-line grep: pack prints `   0.843  doc_1.txt:1-1  (8 tokens)` with
   TWO spaces score→path and TWO spaces range→`(tokens)`. First attempt used
   single spaces → empty integrity list → `set -e` silent abort (RC 1, no
   table). Fixed with ` +` in both gaps.
3. Dead `timed()` fn and stale `NODES_LINE` var removed; `/usr/bin/time`
   capture replaced with `date` deltas (fd juggling kept swallowing output).
