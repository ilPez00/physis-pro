# PH-009 — Test suite speed (closed)

- status: done
- gate: `time cargo test` (< 300 s) + `cargo test -- --ignored --list` +
  `cargo clippy --all-targets -- -D warnings`
- worker: pansa (opencode) on branch `omo-009` → pushed to `agent/omo-research`.

## Baseline (before)

- Full `cargo test --lib`: 1045 passed, **1328 s** (22 min).
- Per-suite (timed individually): http_surface 253 s, adaptive_document 36 s,
  mvp_loop 21 s, rest ≤ 5 s each.
- Stable libtest has no `--format json` / `--report-time` (nightly only), so
  the "10 slowest" table is per-suite + targeted probes, per the packet's
  allowed alternative ("timing per suite OR test-util timing output").

## Root causes (all measured, not guessed)

1. **Classifier rebuild per server build (2.8 s × ~93 http_surface tests).**
   `CellClassifier::build_cached` recomputes 929 seed embeddings on every
   `build_app` because each test uses a fresh temp data dir (seed EmbedCache
   always cold). Probe: `ONTOLOGY_MS=9`, `CLASSIFIER_MS=2833` of 2928 ms total.
2. **CLI tests probed real models (minutes each).** 4 `cli::tests` built
   `PhysisApp` with default config → `select_embedder` tried ollama
   (120 s HTTP timeout) + ONNX loads. Each hung 5+ min; lib tail was 4 stuck
   tests.
3. **Explicit config-RP was gated out.** `select_embedder` honored
   `PHYSIS_EMBEDDER=rp` via early return but sent config-`primary: RP`
   through the semantic self-test gate (hashing fails it) → fell through to
   full model probing. Same bug class as the env bug fixed earlier.

## Fixes

- `CellClassifier::build_shared` (src/classify.rs): process-wide
  `LazyLock<Mutex<HashMap>>` cache keyed by kind + dim + seed hash (name/text/
  domain/mode/facets, **sorted** — seed order follows per-thread HashMap
  iteration; first attempt missed and never hit). `SharedCtx.classifier` and
  `PhysisApp.classifier` are now `Arc<CellClassifier>` (all uses read-only;
  deref covers call sites). First build pays, rest clone.
- `select_embedder`: explicit config-primary RP returns directly, no gate
  (mirrors the env early-return).
- 8 CLI tests use `rp_config()` (explicit RP primary, no env races).
- All 6 `#[ignore]` now carry reasons (`#[ignore = "..."]`); bare form removed.
- `scripts/check-test-tiers.sh` (the packet's meta-test as a runnable gate):
  fast tier ≥ 1300 tests, zero bare ignores, prints the buried heavy tier.
  Two script bugs fixed during implementation: doc-prose `#[ignore]`
  mentions matched the grep (anchored to attribute lines), and `grep -v`
  exiting 1 under `set -o pipefail` killed the script (added `|| true`).
