## Built per task
- **Task 1** (`physis-core/src/backend.rs`): `BackendKind{Cpu,Rocm,Cuda}`
  (env `PHYSIS_BACKEND`, unknown names error), `ComputeBackend` trait
  (kind/label/capabilities/availability/`embed_text` refusal), `CpuBackend`
  over `RandomProjectionEmbedder`, `select_backend` with loud fallback notes.
  Zero `#[cfg(rocm)]`/`#[cfg(cuda)]`.
- **Task 2** (`physis-core/src/devices.rs` + `physis-core hardware` CLI):
  `DeviceInfo`, `HardwareDiscovery::scan` (cpu-always + `nvidia-smi` CSV
  parser + AMD sysfs DRM scan; `rocm-smi` deliberately not parsed),
  `best_kind` ladder. Live run on this box finds AMD card0 (0x67ff, 4 GiB).
- **Task 3** (`cortex/encoder.rs`): `NeuralRole`, `CortexOutput`,
  `SharedEncoder` (one invocation feeds all roles), exemplar `ProbeHead`s,
  cosine `probe` filtered by role. No LFM weights — adapters/probes first.
- **Task 4** (`cortex/latent.rs`): `PhysisLatent` + `W_e/W_d/W_c/W_g`
  (Identity/Linear/MLP, seeded `StdRng` weights, parameter-free centering,
  suppress-only sigmoid gate).
- **Task 5** (`cortex/retrieval.rs`): `RefinementLadder` over `query`
  primitives — exact → structural → sparse → dense → colbert → graph, skips
  carry notes, early-rung-priority dedupe. ColBERT rung reports unavailable.
- **Task 6** (`cortex/router.rs`): verb-table `Intent`, `RoutingDecision`
  with rationale, capable → preferred → scan-best → CPU ladder.
- **Task 7** (`bench::run_backend_table`): per-backend embed-path timing
  table. No model × quantization axis — no such backends exist yet.
- **Task 8 (partial)** (`tests/cortex_contract.rs`): 9 tests over the built
  surface. Full packet gate (`--features embed-onnx`) not run: `ort_sys`
  link fails on this box per repo history (commit `c9f7244`).
- **Task 9** (`src/embed/registry.rs` + `EmbedderConfig.backend`): slot
  override → env → scan-best → CPU, recorded with note; TOML-compatible
  (`#[serde(default)]`).
- **Task 10** (`src/cortex/`): provenance-tagged `CortexIntent`
  (`exact` vs model `compiled_by`), `validate` allowlist
  (`fs.read/inspect/query/embed`); `Execute`/`Unknown` refused; no-shell test.
- **Task 11** (`agents::routing::route_hardware`): compute placement via the

## Surprises
- `Box<dyn ComputeBackend>` method calls resolve without the trait in scope,
  which tripped an unused-import lint — the trait import lives only where the
  trait is named.
- The box this ran on has a live AMD card via sysfs, so the scan-best path
  gets exercised for real, not just in tests.
